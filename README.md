# Codex Plugins

This repository is a monorepo for Codex plugin projects maintained together.

## Projects

- `codex-plugin-cc/`: Claude Code adapter plugin for Codex.
- `codex-ultracode/`: JSON-defined Codex workflow runner plugin with CLI, MCP tools, and packaged workflows.

Each project keeps its own package, plugin manifest, skills, tests, and release notes inside its subdirectory.
